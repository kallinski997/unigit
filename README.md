# UniGit - AI Assistant for Unity

Ein KI-gestütztes Unity-Plugin für beschleunigtes Level-Design und Entwicklung.

## 🎯 Features

- **🤖 AI Chat-Interface** - Natürliche Sprachsteuerung im Unity Editor
- **🏗️ Level Design Automation** - Objekte und Strukturen durch Prompts erstellen
- **📊 Scene Analysis** - Automatische Optimierung und Problem-Erkennung
- **💻 Code Generation** - Scripts und Snippets auf Abruf
- **🎨 Material Helpers** - Einfache Material-Erstellung und -Verwaltung

## 🚀 Quick Start

1. Kopiere `Assets/AIAssistant` in dein Unity-Projekt
2. Öffne `Window > AI Assistant`
3. Tippe einen Befehl wie "create a cube" oder "generate a grid"

Vollständige Anleitung: [`Assets/AIAssistant/QUICKSTART.md`](Assets/AIAssistant/QUICKSTART.md)

- Unity 2020.3+
- C# Editor Tools
- Keine externen Abhängigkeiten
