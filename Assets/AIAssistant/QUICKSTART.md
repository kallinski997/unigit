# AI Assistant for Unity - Quick Start Guide

## Installation

1. **Add to Unity Project**
   - Copy the entire `Assets/AIAssistant` folder into your Unity project's Assets folder
   - Unity will automatically compile the assembly definitions

2. **Open AI Assistant**
   - Go to `Window > AI Assistant` in the Unity menu bar
   - Or use `AI Assistant > Open Window`

## First Steps

### 1. Open the Assistant Window

The AI Assistant window provides an interactive chat interface where you can type natural language commands.

### 2. Try Your First Prompt

Type one of these commands:

```
"Create a cube"
"Generate a grid of objects"
"Add a light to the scene"
```

### 3. Explore Features

The assistant can help with:
- **Level Design**: Creating and arranging objects
- **Scene Analysis**: Finding issues and optimization opportunities
- **Code Generation**: Getting script examples
- **Material Creation**: Creating and applying materials

## Common Commands

### Level Design
- `create cube` - Creates a cube primitive
- `create grid` - Generates a grid of objects
- `create room` - Generates a basic room structure
- `add light` - Adds lighting to the scene

### Analysis
- `analyze scene` - Analyzes current scene for issues
- `check performance` - Gets performance metrics
- `optimize` - Suggests optimizations

### Code
- `movement script` - Generates a player movement script
- `trigger example` - Shows trigger zone code
- `rotation code` - Creates rotation script

### Materials
- `create material` - Creates a new material
- `emissive material` - Creates a glowing material

## Quick Actions Menu

Access fast commands via the Unity menu:

```
AI Assistant >
  ├── Quick Actions
  │   ├── Create Grid 5x5
  │   ├── Create Basic Room
  │   └── Add Directional Light
  ├── Analysis
  │   ├── Analyze Current Scene
  │   ├── Find Missing Scripts
  │   └── Find Empty GameObjects
  └── Level Design
      ├── Arrange in Line
      └── Arrange in Circle
```

## Keyboard Shortcuts

- `Ctrl + Enter` - Submit prompt in chat window
- `Clear` button - Reset conversation
